# Field Boundary Detection Workflow

This document outlines a multi-stage workflow for detecting and refining agricultural field boundaries from geospatial data. The process involves a series of five interconnected Jupyter notebooks, each performing a step of aggregation, filtering, and accuracy assessment. The ultimate goal is to produce a highly accurate and clean set of field boundary polygons.

| Stage | Notebook | What it does |
|---|---|---|
| Workflow 1 | `Workflow1_v4.ipynb` | Merge adjacent SAM polygons within a tile set; area, NDVI, and compactness filtering. |
| Workflow 2 | `Workflow2_v3.ipynb` | Merge predictions across SAM checkpoints (ViT-B, ViT-L, ViT-H). |
| Workflow 3 | `Workflow3_v2.ipynb` | Merge predictions across input tile sizes within an acquisition date. |
| Workflow 4 | `Workflow4_v1.ipynb` | Merge predictions across the four acquisition dates (T1–T4). |
| Workflow 5 | `Workflow5_v1.ipynb` | Merge original and edge-enhanced image predictions. |
| Plots | `PlotsForPaper_Share_v3.ipynb`, `ReviewersPlots_v1.ipynb` | Manuscript and reviewer-response figures. |
| Utilities | `utils.py` | Geometry merging, overlap resolution, accuracy metrics. |

## Dependencies

The notebooks rely on `geopandas`, `shapely`, `geoplanar`, `numpy`, `pandas`, `rasterio`, and `matplotlib`. SAM inference itself uses [`samgeo`](https://samgeo.gishub.org/). A complete environment file may be added in a future revision; for now, install the listed packages into a fresh Python environment.

## Overall Workflow Summary

The workflow is a hierarchical aggregation and refinement process. It starts with raw polygon predictions from a Segment Anything Model (SAM) and progressively merges them to create a more robust and accurate final product. Each step of the workflow involves merging predictions, resolving overlaps, and performing an accuracy assessment against a ground truth dataset.

The aggregation strategy is as follows:
1.  **Workflow 1:** Merges adjacent polygons within the same prediction set.
2.  **Workflow 2:** Merges predictions from different model checkpoints for the same data group.
3.  **Workflow 3:** Merges predictions from different data groups within the same epoch.
4.  **Workflow 4:** Merges predictions from all different epochs.
5.  **Workflow 5:** Merges the final predictions from two different image sources (original and edge-enhanced).

## Key Dependencies

The entire workflow relies on a set of utility functions defined in the `utils.py` file. The key functions in this file are:

*   `merge_adjacent_tiles`: Merges polygons in adjacent tiles based on an overlap threshold.
*   `wflow1_iou_threshold_metrics`: Calculates Intersection over Union (IoU), precision, recall, and F1-score for accuracy assessment.
*   `overlap_resolution_single`: Resolves overlaps between polygons in a single GeoDataFrame.
*   `island_resolution`: Handles cases where small polygons are contained within larger ones.
*   `trim_overlaps`: Trims overlapping polygons, with an option to keep the largest one.

The workflow also heavily utilizes the `geopandas` library for geospatial data manipulation.

## Workflow 1: Initial Polygon Merging and Filtering

**Notebook:** `Workflow1_v4.ipynb`

### Objective
To merge adjacent predicted field boundary polygons from a Segment Anything Model (SAM) and perform an initial accuracy assessment.

### Inputs
*   Raw GeoPackage files with predicted field boundaries from SAM.
*   A ground truth shapefile.
*   A maximum NDVI raster file.

### Processing Steps
1.  **Merge Adjacent Tiles:**
    *   Iterates through different folders of predictions.
    *   Applies an area-based filter to remove very small and very large polygons.
    *   Uses the `merge_adjacent_tiles` function to merge polygons in adjacent tiles with a high boundary overlap.
    *   Applies another area-based filter after merging.
    *   Simplifies and regularizes geometries using the `make_rectangularish` function.
    *   Uses `geoplanar.trim_overlaps` to handle any remaining overlaps.
    *   Saves the processed GeoDataFrames as new GeoPackage files with a `_Workflow1Merged.gpkg` suffix.

2.  **Accuracy Assessment:**
    *   Iterates through the newly created `_Workflow1Merged.gpkg` files.
    *   Filters the ground truth data based on an NDVI threshold.
    *   Calculates the mean NDVI for each predicted polygon and filters them.
    *   Filters polygons based on a compactness measure.
    *   Saves the cleaned predicted polygons to a new file with a `_V2.gpkg` suffix.
    *   Calculates area-based precision, recall, and F1-score.
    *   Calculates the percentage of detected ground truth polygons and the average IoU.
    *   Saves all metrics to a CSV file: `..._Workflow1Metrics_v1.csv`.

## Workflow 2: Merging Predictions from Different Checkpoints

**Notebook:** `Workflow2_v3.ipynb`

### Objective
To merge the cleaned predictions from Workflow 1 that were generated by different model checkpoints (e.g., `vit_b`, `vit_h`, `vit_l`) and assess the accuracy of the combined result.

### Inputs
*   The cleaned GeoPackage files (`..._V2.gpkg`) generated in Workflow 1.
*   The ground truth shapefile.

### Processing Steps
1.  **Merge Checkpoint Predictions:**
    *   Groups the input files from Workflow 1 based on their data group (e.g., `T1_12by12`).
    *   For each group, concatenates the GeoDataFrames from the different model checkpoints.
    *   Resolves overlaps between the merged polygons using `overlap_resolution_single` and `trim_overlaps`.
    *   Applies a compactness filter and cleans geometries with buffering.
    *   Saves the final merged GeoDataFrame to a new file with a `_Workflow2Merged_V2.gpkg` suffix.

2.  **Accuracy Assessment:**
    *   Repeats the accuracy assessment process from Workflow 1 on the new `_Workflow2Merged_V2.gpkg` files (without the NDVI filtering step).
    *   Saves the metrics to a new CSV file: `..._Workflow2Metrics_v1.csv`.

## Workflow 3: Merging Predictions from Different Data Groups

**Notebook:** `Workflow3_v2.ipynb`

### Objective
To merge the predictions from Workflow 2, which were already combined across model checkpoints. This workflow now combines all the different data groups (e.g., `12x12`, `3x3`) within a single "epoch" (e.g., `T1`).

### Inputs
*   The merged GeoPackage files (`..._V2.gpkg`) generated in Workflow 2.
*   The ground truth shapefile.

### Processing Steps
1.  **Merge Data Group Predictions:**
    *   Iterates through the "epochs" (`T1`, `T2`, `T3`, `T4`).
    *   For each epoch, concatenates all the GeoDataFrames from Workflow 2 that belong to it.
    *   The subsequent processing is identical to Workflow 2: overlap resolution, compactness filtering, and geometry cleaning.
    *   Saves the merged GeoDataFrame for each epoch to a new file with a `_Workflow3Merged.gpkg` suffix.

2.  **Accuracy Assessment:**
    *   Repeats the accuracy assessment on the new `_Workflow3Merged.gpkg` files.
    *   Saves the metrics to a CSV file: `..._Workflow3Metrics_v1.csv`.

---

## Workflow 4: Merging Predictions from Different Times

**Notebook:** `Workflow4_v1.ipynb`

### Objective
To merge the predictions from Workflow 3, which were already aggregated by epoch. This workflow combines all epochs (`T1`, `T2`, `T3`, `T4`) into a single, final set of predictions.

### Inputs
*   The merged GeoPackage files (`..._Workflow3Merged.gpkg`) generated in Workflow 3.
*   The ground truth shapefile.

### Processing Steps
1.  **Merge All Predictions:**
    *   Concatenates all the output files from Workflow 3 into a single GeoDataFrame.
    *   The subsequent processing is identical to the previous workflows.
    *   Saves the final, fully merged GeoDataFrame as `AllTime_Segmented_Workflow4Merged.gpkg`.

2.  **Accuracy Assessment:**
    *   Performs the final accuracy assessment on this comprehensive dataset.
    *   Calculates the standard set of metrics and saves them to `..._Workflow4Metrics_v1.csv`.
    *   Includes an additional scatter plot comparing the area of the ground truth polygons to the predicted polygons.

---

## Workflow 5: Merging Predictions from Original and Edge-Enhanced Images

**Notebook:** `Workflow5_v1.ipynb`

### Objective
To merge the final, aggregated predictions from Workflow 4 with a corresponding set of predictions derived from "edge-enhanced" images.

### Inputs
*   The final merged GeoPackage files from Workflow 4 (`AllTime_Segmented_Workflow4Merged.gpkg` and `AllTime_Enhanced_Segmented_Workflow4Merged.gpkg`).
*   The ground truth shapefile.

### Processing Steps
1.  **Merge Original and Enhanced Predictions:**
    *   Concatenates the two final files from Workflow 4.
    *   Removes duplicate geometries.
    *   The subsequent processing is similar to previous workflows, with the addition of a more explicit step to remove "island" polygons using `STRtree`.
    *   Saves the final, combined GeoDataFrame as `AllTime_Segmented_Workflow5Merged_og.gpkg`.

2.  **Accuracy Assessment:**
    *   Performs the ultimate accuracy assessment on this final merged file.
    *   Saves the metrics to a CSV file: `..._Workflow5Metrics_v1.csv`.

## Final Output

The final output of this entire workflow is a single GeoPackage file, `AllTime_Segmented_Workflow5Merged_og.gpkg`, containing the most refined and accurate set of field boundary predictions, along with a series of CSV files containing the accuracy metrics at each stage of the process.
